# Чуйка — спортивный вестник

Веб-приложение на React и Vite для просмотра математических прогнозов футбольных и хоккейных матчей.

## Требования

- Node.js и npm;
- доступ к командной строке (PowerShell, Windows Terminal или аналогичной).

Проверить установку Node.js можно:

```powershell
node --version
npm --version
```

## Установка

Перейдите в каталог фронтенда:

```powershell
cd "\chuika frontend\chuika\frontend"
```

Установите зависимости:

```powershell
npm install
```

## Запуск в режиме разработки

Запустите локальный сервер:

```powershell
npm run dev
```

После запуска откройте:

```text
http://localhost:3000
```

Сайт поддерживает автоматическое обновление страницы при изменении исходных файлов.

## Проверка проекта

Проверка TypeScript:

```powershell
npm run lint
```

Проверка production-сборки:

```powershell
npm run build
```

## Просмотр production-сборки

Сначала соберите проект:

```powershell
npm run build
```

Затем запустите локальный сервер для просмотра готовой сборки:

```powershell
npm run preview
```

Откройте адрес, который напечатает Vite в терминале. Обычно это:

```text
http://localhost:4173
```

## Конфигурация API

По умолчанию приложение работает в демонстрационном режиме с локальными тестовыми данными. Для запуска этого режима дополнительная конфигурация не требуется.

Если нужно подключить внешний API:

1. Скопируйте `.env.example` в `.env.local`.
2. Укажите адрес API в переменной `VITE_API_BASE_URL`.
3. При необходимости укажите ключ в переменной `VITE_API_KEY`.
4. Откройте панель `OpenAPI` в приложении и отключите демонстрационный режим.

Пример `.env.local`:

```dotenv
VITE_API_BASE_URL=https://example.com/api/v1
VITE_API_KEY=your-api-key
```
Файл `.env.local` предназначен только для локальной настройки.

## Возможности приложения

- прогнозы только для футбольных и хоккейных матчей;
- фильтрация по виду спорта, периоду и дате;
- поиск по командам и лигам;
- карточки матчей с вероятностями исходов;
- подробный разбор выбранного матча;
- просмотр параметров API и OpenAPI-контракта.
